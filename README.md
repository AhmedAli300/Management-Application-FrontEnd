# Management Application

A modern project and task management application built with **React**, **Vite**, and **Socket.IO**, featuring authentication, project management, task tracking, and real-time updates.

## Live Demo

👉 https://management-application-8kbm.vercel.app/

## Features

- User Authentication
- Protected Routes
- Project Management
- Task Management
- Team Members
- Real-time Updates (Socket.IO)
- Responsive UI

## 🛠 Tech Stack

- React 19
- Vite
- React Router DOM
- Axios
- Bootstrap 5
- Socket.IO Client
- React Hot Toast

## Installation

```bash
git clone https://github.com/your-username/management-application-frontend.git

cd management-application-frontend

npm install

npm run dev
```

## Environment Variables

Create a `.env` file in the project root:

```env
VITE_API_URL=your_backend_api
VITE_SOCKET_URL=your_socket_server
```

## Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm run test     # Run tests
```
